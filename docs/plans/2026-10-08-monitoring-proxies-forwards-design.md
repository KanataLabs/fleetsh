# Monitoring, inherited SSH proxies and port forwards

- Add `alive [SELECTOR]` and `stats [SELECTOR]`, defaulting to `@all`, using the existing SSH executor, bounds, trust and JSON reporting. Liveness means authenticated SSH execution. Linux stats are a single snapshot: sampled CPU busy percentage, memory and swap usage, `whoami`, and `df -h`.
- Extend `[defaults]` with proxy/proxy_credential. Hosts inherit only when no explicit proxy or ProxyJump is configured. An explicit host proxy has its own credential; `direct` disables inheritance. Support SOCKS5 and HTTP/HTTPS CONNECT without URL userinfo.
- Store named `[[hosts.ALIAS.forwards]]` profiles (`local`, `remote`, `dynamic`) with listen and destination fields. `forward HOST [NAME]` starts them explicitly; `--dry-run` prints configuration without network access. Dynamic forwarding offers unauthenticated SOCKS5 TCP CONNECT; use loopback binds by default. All types use verified SSH and close listeners and active streams on cancellation/disconnect.
- Verify real bidirectional traffic for each type, authenticated/inherited/overridden proxies, setup rollback, cancellation and malformed SOCKS requests with localhost fixtures. Test stats against Linux proc fixtures and verify the command against the previously authorized VPS read-only.
- Update English-first built-in help/offline guides and separate English/Japanese/Chinese online documentation. Commit and push with the organization Publisher App, publish gh-pages, then tag `v0.1.0-alpha.1` after successful CI. Any release publication must also use the Publisher App, rather than the workflow token.
