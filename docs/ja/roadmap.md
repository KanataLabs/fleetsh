# ロードマップ

## 現在：v0.1 の開発実装

- [x] KanataLabs の公開 Go リポジトリ、GPL-3.0-only。
- [x] ホスト一覧の add/edit/rm/ls/show、グループ、タグ、コンソール専用ホスト。
- [x] 暗号化鍵を含む秘密鍵、パスワード、SSH Agent。
- [x] OS 認証情報ストアと端末の非表示入力。
- [x] 直接 SSH、ProxyJump、認証付き SOCKS5。
- [x] 対話 PTY とシェル、ホスト鍵の信頼・表示・リセット、接続維持と期限。
- [x] 単一と複数ホストの実行、並列数制限、ホストごとの結果、JSON、出力上限。
- [x] OS 検出、ドライラン、承認付き Linux 更新。
- [x] 再接続、新しい起動 ID、正常性確認付き再起動。
- [x] チャネル経由の sudo パスワード入力と直列実行。
- [x] クロスプラットフォーム CI、リリースのパッケージ化、main から gh-pages への公開。
- [x] Windows/macOS/Linux のユーザー用およびシステム用 PATH 設定。
- [ ] 最初のタグ付きリリースの実行ファイルとチェックサム。
- [ ] 安定版とする前の実 VPS での手動受け入れ確認。

実装済み機能はローカルのテスト環境で検証しています。現在は開発版で、安定版は未公開です。

## v0.2：利便性と相互運用

- [ ] HTTP CONNECT プロキシ。
- [ ] status と reboot-required。
- [ ] 独自のコマンド別名と `run`。
- [ ] OpenSSH 設定のインポートと TOML/JSON/OpenSSH のエクスポート。
- [ ] 接続の再試行と段階的な実行。

当初の設計は HTTP CONNECT を P0 と v0.2 の両方に含めていましたが、
ロードマップでは v0.2 とします。別名と `run` も v0.2 の予定です。
sudo の認証情報参照と直列実行は、基本の実行処理とともに実装済みです。

## v0.3：転送と対話ツール

- [ ] SFTP アップロードとダウンロード、ポート転送。
- [ ] OS に応じたコマンドプロファイル。
- [ ] マスキングと保存期間の方針を持つ、任意の履歴とログ。
- [ ] Bash/Zsh/PowerShell の補完。
- [ ] 任意の TUI。

## リリースの確認項目

- [x] 接続先と踏み台の鍵検証、未知の鍵の拒否、変更された鍵の拒否。
- [x] 平文秘密値フィールドの拒否、チャネル経由の sudo。
- [x] 認証付きプロキシとキャンセルのローカル検証。
- [x] 並列数、出力の切り詰め、複数種類の失敗の終了コード。
- [x] 更新の承認と事前確認、再起動 ID の検証。
- [x] OS とアーキテクチャごとの CGO 不要の単一実行ファイル。
- [x] 全対応プラットフォームでの OS 認証情報ストア統合 CI。
- [ ] 端末と PTY の手動受け入れ確認、実 VPS での操作検証。
- [ ] レビュー済みのタグ付きリリース。

## 対象外

複雑な YAML プレイブック、望ましい状態の構成管理、テンプレート言語、ロール、
コレクション、リモート Agent、中央デーモン、Web UI、スケジュール実行、
Terraform の置換、Kubernetes 管理、サービス検出、CMDB。
