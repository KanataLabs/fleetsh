Passwords and credentials
=========================
Save an SSH password directly when adding a host:

  fleetsh add hk1 --host hk1.example.com --user ubuntu --auth password

When --credential is absent, fleetsh prompts twice with hidden input and stores
the secret in the OS credential store. It writes only the generated reference
to the inventory. References start with fleetsh-ssh-HOST- followed by a random
suffix (long aliases are shortened). Native entries use the fleetsh namespace
and the note: Created by fleetsh (KanataLabs). Managed VPS credential.
Existing entries get these markers when replaced; they are not auto-migrated.

Saved the wrong password?
  npx fleetsh edit hk1 --save-password
  npx fleetsh ssh hk1

Enter the correct server password twice at the hidden prompts. This replaces
only the local saved copy, not the server's password. There is no need to create
or find a credential reference manually. --auth password alone keeps a saved
password reference; --save-password explicitly replaces it. To switch a key or
agent host, use edit hk1 --auth password --save-password.
Keep --config PATH on every command when using a custom inventory.
Bare edit hk1 shows help; use show hk1 to inspect settings.

Read this guide with npx fleetsh docs password or npx fleetsh docs passwords.
Keep spaces between fleetsh, docs and password. npx fleetshdocs asks npm for a
different package and fails before fleetsh runs.

Rotate the stored password or choose per-connection prompting:

  fleetsh edit hk1 --save-password
  fleetsh edit hk1 --auth password --no-save-password

--save-password creates a new reference, leaving the previous secret intact.
--no-save-password detaches the stored reference; it does not delete the secret.
Neither flag accepts an explicit nonempty --credential. Hidden prompts require
a real terminal and an available store. No password argument or stdin-file import
is supported. Removing a host leaves credentials intact for other hosts.

The credential commands remain available for shared or specialized secrets:

  fleetsh credential add shared-login
  fleetsh edit hk1 --auth password --credential shared-login
  fleetsh credential add admin-sudo
  fleetsh edit hk1 --sudo-credential admin-sudo
  fleetsh credential add key-passphrase
  fleetsh edit hk1 --auth key --key ~/.ssh/id_ed25519 --credential key-passphrase

Enter the secret only at the hidden prompt. For SOCKS5 enter username:password.
credential add REF --replace changes every host that uses the same reference.
credential ls lists tracked/used references; it neither reveals secret values
nor scans every OS-store item. credential rm REF deletes a secret and its index
entry but leaves host fields intact. Edit those fields before further connections.

  fleetsh credential ls
  fleetsh show hk1
  fleetsh credential rm old-login

SSH password saving does not change the server's password, nor automatically
configure sudo. Set sudo_credential explicitly or use passwordless sudo.
On headless Linux, use a supported unlocked Secret Service or SSH key/agent
authentication; fleetsh never saves plaintext as a fallback.
