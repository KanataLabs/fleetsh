# fleetsh v0.1 Core Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver inventory, secure SSH, credentials, proxies and bounded actions; document PATH installation.
**Architecture:** Cobra calls validated TOML inventory, native credential adapters and in-process SSH.
**Tech Stack:** Go, Cobra, go-toml/v2, x/crypto/ssh, x/net/proxy, x/term, go-keyring, go-winio, flock.

### Task 1: Inventory
Implement strict schema, locked atomic mutations, selectors and CRUD. Test invalid schema, proxy cycles, plaintext-secret rejection and concurrent mutations.

### Task 2: Credentials and SSH
Implement hidden input, keyring references, SSH key/password/agent, ProxyJump/SOCKS5, known_hosts trust, changed-key refusal, keepalive and cancellation. Use local fixtures without real VPS credentials.

### Task 3: Executor and actions
Implement bounded exec, JSON, skipping, deadlines, safe sudo input, PTY, update dry run/confirmation and reboot identity verification. Test failures and cancellation.

### Task 4: CLI and documentation
Wire commands with Cobra. Document actual flags and user/system PATH registration; update status and release gates. Do not alter this machine's PATH.

### Task 5: Verify and publish
Run formatting, race tests, vet, six CGO-free cross-builds and smoke tests. Push and verify CI and docs. Distinguish supported native adapters from platforms exercised.
