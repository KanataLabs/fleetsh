# 路线图

## 当前：v0.1 开发实现

- [x] KanataLabs 下的公开 Go 仓库，GPL-3.0-only 许可证。
- [x] 主机增删改查、分组和标签、仅控制台资产。
- [x] SSH 密钥（含加密密钥）、密码和 SSH Agent。
- [x] 原生系统凭据适配和隐藏终端输入。
- [x] 直连 SSH、跳板和带认证的 SOCKS5。
- [x] 交互 PTY 与 shell、主机密钥信任和查看重置、保活和超时。
- [x] 单机和批量命令、并发限制、按主机返回结果、JSON 和输出上限。
- [x] Linux 更新：系统识别、预演和确认。
- [x] 重启：重新连接、新启动标识和健康探测。
- [x] 通过通道输入 sudo 凭据，串行执行。
- [x] 跨平台持续集成、发布打包流程、main 到 gh-pages 文档发布。
- [x] Windows、macOS 和 Linux 的用户级及系统级 PATH 安装说明。
- [ ] 首个带版本标签的二进制发行版和校验和。
- [ ] 宣布稳定版前的真实 VPS 手动验收。

已实现功能使用本地测试环境验证，目前仍是开发版，尚未发布稳定版本。

## v0.2：便利性与互操作

- [ ] HTTP CONNECT 代理。
- [ ] 状态查看及重启需求检查。
- [ ] 自定义命令别名和 `run`。
- [ ] OpenSSH 配置导入，TOML、JSON 和 OpenSSH 导出。
- [ ] 连接重试和滚动执行。

原始方案同时将 HTTP CONNECT 列为 P0 和 v0.2，本路线图采用 v0.2。
命令别名和 `run` 也保留在 v0.2。
sudo 凭据引用和串行执行已随核心执行器实现。

## v0.3：文件传输与交互工具

- [ ] SFTP 上传下载和端口转发。
- [ ] 按操作系统选择命令配置。
- [ ] 可选历史与日志，配套脱敏和保留策略。
- [ ] Bash、Zsh 和 PowerShell 补全。
- [ ] 可选终端交互界面。

## 发布条件

- [x] 目标与跳板密钥验证，拒绝未知和变化的密钥。
- [x] 拒绝明文凭据字段，通过通道传送 sudo 密码。
- [x] 本地测试覆盖认证代理和取消。
- [x] 测试并发限制、输出截断和混合错误退出码。
- [x] 测试更新确认、预检查和重启身份验证。
- [x] 跨操作系统及架构构建不依赖 CGO 的单个二进制文件。
- [x] 原生凭据集成持续集成在全部支持平台通过。
- [ ] 手动终端与 PTY 验收，以及真实 VPS 动作验证。
- [ ] 审查并发布带版本标签的发行版。
